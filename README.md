# نظام كاشير محل ملابس

نظام كاشير يعمل من المتصفح بدون سيرفر وبدون إنترنت (ملف واحد `index.html`). البيانات تتحفظ على نفس الجهاز.

- منتجات بمقاسات وألوان وكمية لكل متغير
- باركود لكل قطعة وطباعة ملصقات (Code 39)
- بيع بالسكانر (السكانر بيعمل مثل الكيبورد) أو بالبحث
- خصومات: نسبة، مبلغ، نص السعر، 2 بسعر 1
- دفع: نقدي، فيزا، فودافون كاش، آجل
- مرتجع واستبدال بالفاتورة، والمخزون بيتحدث
- مخزون: استلام بضاعة، جرد، تنبيه نقص
- تقارير: مبيعات يومية، ربح، الأكثر مبيعاً، مخزون راكد
- وردية وتقفيل، نسخة احتياطية، فاتورة مطبوعة
