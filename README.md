# نظام كاشير محل ملابس (Clothing POS) v2

برنامج ويندوز (Electron + SQLite) شغال أوفلاين، ومعاه نسخة المتصفح (index.html).

- خصم بمبلغ أو نسبة على الصنف أو على الفاتورة كلها
- مقاسات وألوان ومخزون لكل مقاس، تنبيه نقص (عام أو لكل منتج)
- مرتجع واستبدال بالفاتورة
- عملاء ونقاط ولاء وسجل مشتريات
- كاشير متعدد بأرقام سرية وصلاحيات وحد خصم، وتقرير لكل كاشير
- تقارير يومية وشهرية وتصدير CSV
- تقفيل وردية وجرد الدرج ومصروفات
- دفع مختلط وبيع آجل مع متابعة الديون
- طباعة باركود (نسخة لكل قطعة أو بعدد الكمية)
- نسخ احتياطي تلقائي واسترجاع
- أوفلاين مع مزامنة عبر فولدر مشترك
- إرسال الفاتورة على واتساب
- أكثر من فرع ومخزن وتحويل بينهم

أول دخول: المدير / الرقم السري 1234 (بيطلب تغييره).
